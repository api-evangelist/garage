# Garage

> Garage (Garage Technologies, Inc., withgarage.com / shopgarage.com) is America's online marketplace for buying and selling specialized vehicles and equipment — fire trucks, ambulances, and heavy-duty municipal apparatus. It handles listings, AI-powered appraisals, virtual inspections, payments, freight, financing, and warranties for fire departments, EMS services, municipalities, and dealers.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public company profile. Garage does not currently publish a public developer/API program; no OpenAPI, MCP server, SDKs, or public API documentation were found during enrichment.
